# 매집점수(prepump_score) 계산 기준

기준: 2026-11-26 `trading_server.py` `calculate_prepump_score` → `_prepump_v7` (PREPUMP_SCORE_VERSION = 7, 10/12부터) · 빗썸·업비트·바이낸스 공통

## 1. 계산 순서

| 단계 | 내용 |
|---|---|
| ① 원점수 | s = 3일 등락 + 박스 위치 + EMA20 거리 + RSI + ATR + 24h 변동계수 (6항목, 1시간봉 기준) |
| ② 환산 | 점수 = s × 100 ÷ 78 |
| ③ 하락장 | 레짐이 하락장이면 × 80/90 (≈ 0.89 — 하락장에선 컷 80이 사실상 90이 되는 효과) |
| ④ 범위 | 반올림 후 0~100으로 자름 |

- 원점수 최대 85 → 환산 109 → 100에서 잘림. 원점수 62.4 이상이면 80점(하락장은 70.2 이상)
- 성격: "많이 안 오르고 눌린 자리에서 조용히 쌓이는 코인" — 3일 등락·박스 하단·EMA20 아래·RSI 낮음이 핵심
- 판정 롱 후보: 매집 ≥ 80 **그리고** 롱 조건식 v7(`RSI<35` / `recent_pct<-5 & 30분<-1%` / `BB%<0 & ATR>1 & OI<-1%` 중 하나) — 롱점수 ≥ 50과 OR

## 2. 항목별 배점

### ① 3일 등락 (recent_pct = 72봉 전 대비 %, 최대 20)

| 3일 등락 | 점수 |
|---|---|
| ≤ -10% | 20 |
| ≤ -5% | 18 |
| ≤ -2% | 12 |
| ≤ 0% | 8 |
| ≤ +3% | 4 |
| ≤ +10% | 0 |
| > +10% | **-10** |

### ② 박스 위치 (최근 20봉 고저 안에서 현재가 위치 %, 최대 15)

| 박스 위치 | 점수 |
|---|---|
| ≤ 10% (하단) | 15 |
| ≤ 25% | 12 |
| ≤ 50% | 7 |
| ≤ 80% | 2 |
| > 80% | 0 |

- 박스 고가 = 저가(계산 불가)면 0점

### ③ EMA20 거리 ((현재가 ÷ EMA20 - 1) %, 최대 15)

| EMA20 대비 | 점수 |
|---|---|
| < -4% (너무 깊게 빠짐) | 8 |
| -4% ~ -0.5% (눌림) | **15** |
| -0.5% ~ +0.5% | 6 |
| +0.5% ~ +2% | 2 |
| > +2% | 0 |

### ④ RSI (최대 15)

| RSI | 점수 |
|---|---|
| < 30 | 12 |
| 30 ~ 40 | **15** |
| 40 ~ 45 | 12 |
| 45 ~ 50 | 8 |
| 50 ~ 55 | 4 |
| > 55 | 0 |

### ⑤ 1h ATR % (최대 10)

| ATR | 점수 |
|---|---|
| < 0.5% | 0 |
| 0.5 ~ 0.9% | 4 |
| 0.9 ~ 1.5% | 7 |
| 1.5 ~ 3% | **10** |
| > 3% | 0 |

### ⑥ 24h 가격 변동계수 (24봉 종가 표준편차 ÷ 평균, 최대 10)

| 변동계수 | 점수 |
|---|---|
| < 0.006 (죽은 코인) | 0 |
| 0.0129 ~ 0.0166 | 6 |
| 0.0166 ~ 0.0241 | **10** |
| 그 외 (0.006 ~ 0.0129, ≥ 0.0241) | 3 |
