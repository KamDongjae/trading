## 5. 이번에 반영한 개선

### data_collector.py
1. **레짐 갱신 (핵심 버그 수정)**: 매 사이클 `detect_market_regime`으로 레짐을 판정하고, 점수 계산 때 쓴 레짐과 다르면 바뀐 레짐으로 한 번 더 계산함. 이제 로그 점수가 서버 화면 점수와 같은 로직으로 남음
2. **로그 컬럼 12개 추가**: `regime`, `extension_pct`, `ema20_slope_pct`, `price_cv_24h`, `chg_5m`, `chg_15m`, `momentum_blend`, RSI/BB 체류시간 4개, `hl_flag`. 점수 계산에 들어가는데 로그에 없던 값이라, 이제 서버 점수를 오프라인에서 그대로 재현할 수 있음
3. **헤더 자동 마이그레이션**: 진행 중인 파일이 예전 헤더면 기존 행에 빈 칸을 채워서 새 헤더로 다시 씀. 원본은 `.bak`로 보관
4. **고정 주기**: 수집 시간만큼 간격이 밀리던 걸(5.38분) 정확히 5분으로 맞춤

### trading_server.py
1. **3일 급등 후 숏 보너스** `score_runup_short_bonus` (+5 / +8점, 횡보장 제외, `USE_RUNUP_SHORT_BONUS`로 끌 수 있음)
   - 근거: recent_pct ≥ 10일 때 24h 초과수익(숏) A +3.68% / B +3.11%, 상위 급등 6종목을 빼도 A +3.49% / B +1.53%
   - 기존 short_score에 얹어서 다시 계산하면 B 구간 short ≥ 55의 24h 초과수익이 +0.60% → +1.96%
   - 롱 쪽 반등 보너스는 상위 종목을 빼면 효과가 사라져서(+0.12 / -0.43%) 손대지 않음
2. **빗썸 전체시세 캐시** (5초): `process_ticker`가 종목마다 `get_current_price("ALL")`을 따로 불러 사이클당 40번 나가던 걸 1~2번으로 줄임. None 응답이 오면 직전 값을 씀
3. `process_ticker` 결과에 레짐·체류시간 등 계산 입력값 추가 (수집기 기록용, 주문 로직에는 영향 없음)
4. `server_market.csv` 맨 뒤에 `regime` 칸 추가 (맨 뒤라 구버전 클라이언트와도 호환)

### trading_client.py
1. 상단 서버 상태 줄에 **현재 레짐** 표시
2. 카드 2번째 줄에 **3일 등락%** 표시 (가장 강한 신호인데 카드에 안 보였음)
3. **평균회귀 뱃지**: 3일 +10% 이상이면 "📉 급등 — 24h 되돌림 우세", +15% 이상이면 "과열" 표시. 롱 진입 테두리와 겹치면 "롱 추격 주의"도 붙음. 기존 충돌 뱃지와 같은 줄에 같이 표시됨
